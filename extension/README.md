# 🔌 Golden Crown BLS Bridge — Chrome Extension

هذا الامتداد ينفّذ **مهام الحجز داخل متصفح Chrome حقيقي** حيث تكون **مسجّل الدخول مسبقًا إلى حسابك في BLS**.
لذلك لا يوجد حظر، لأن الطلبات حقيقية من متصفحك أنت.

---

## ⚡ التثبيت (3 دقائق)

### الخطوة 1 — تفعيل وضع المطوّر
1. افتح في Chrome: **`chrome://extensions`**
2. فعّل مفتاح **«وضع المطوّر / Developer mode»** في أعلى الصفحة

### الخطوة 2 — تحميل الامتداد
1. في نفس الصفحة اضغط **«تحميل غير محزومة / Load unpacked»**
2. اختر مجلد **`extension/`** في مشروعك

### الخطوة 3 — تسجيل الدخول إلى BLS
1. افتح تبويب جديد: **https://algeria.blsspainvisa.com**
2. **سجّل الدخول إلى حسابك** (مرة واحدة فقط)
3. اترك هذا التبويب **مفتوحًا**

### الخطوة 4 — الربط بالموقع
1. اضغط أيقونة الامتداد في Chrome
2. الصق **كود الاقتران** من موقعك:
   - المشغّل: **واجهة المشغّل ← تبويب 🔌 الجسر**
   - العميل: **بوابة العميل ← قسم ربط المتصفح**
3. اضغط **«Save & connect»**
4. تأكد أن الحالة تصبح: **🟢 Connected · BLS session ready**

## ⚙️ المهام المدعومة

| المهمة | الوصف |
|---|---|
| `PING` | نبضة معظم — يسجّل أن الامتداد حي |
| `OPEN_BOOKING` | يفتح صفحة الحجز ويختار المركز/الفئة/نوع الحجز |
| `FILL_FORM` | يملأ **54 حقل** (مطابق لاستمارة BLS الرسمية) |
| `SUBMIT` | يضغط Submit ثم يقرأ رقم الحجز |
| `READ_CAPTCHA` | يلتقط صورة الكابتشا ويرسلها للمشغّل |

---

## 🔐 لماذا لا يوجد حظر؟

| الطبقة | الحماية |
|---|---|
| **TLS/HTTP** | طلبات HTTPS حقيقية من متصفحك |
| **الكوكيز** | جلسة BLS الحقيقية الخاصة بحسابك ✅ |
| **البصمة (Fingerprint)** | بصمة Chrome/JavaScript الحقيقية ✅ |
| **التوقيت** | يفتح قبل الموعد بـ 45 ثانية (تسخين مسبق) |
| **الكابتشا** | **إنسان** يحلّه — لا يوجد أي أتمتة لكابتشا |

## ❓ حل المشاكل

| المشكلة | الحل |
|---|---|
| `Not paired` | تأكد أن كود الاقتران مطابق وبحروف كبيرة |
| `Pairing code not recognised` | إعادة توليد الكود من الموقع ثم إعادة الحفظ |
| `waiting for BLS tab` | افتح تبويب **algeria.blsspainvisa.com** وسجّل دخولك |
| `BLS tab not open` | افتح الموقع في تبويب ثابت **ولا تغلقه** |
| `unmatched` في السجل | بعض أسماء الحقول تغيّرت في BLS — حدّث `content.js` |

## 📁 الملفات

| الملف | الدور |
|---|---|
| `manifest.json` | إعدادات الامتداد (MV3) |
| `background.js` | العامل الخلفي — يسحب المهام وينفّذها |
| `content.js` | يعمل **داخل صفحة BLS** — يملأ الحقول |
| `popup.html/js` | نافذة الامتداد — الحالة وكود الاقتران |
| `icon128.png` | أيقونة الامتداد |
